# 📱 Basic Calculator Mobile Application

A simple and user-friendly Android calculator application built to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

This project was developed as a beginner-friendly Android application using Android Studio.

---

# ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear Input Function
- 📱 Responsive Mobile UI
- ⚡ Fast and Simple Calculations
- 🎨 Clean User Interface

---

# 🛠️ Technologies Used

- Kotlin / Java
- Android Studio
- XML Layout Design
- Android SDK
